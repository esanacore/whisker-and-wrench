Tools, plans and software to help animal shelters and animal control. Domain: whiskerandwrench.com (pending registration).

## What's here

- **plans/001-shelter-cot/guide.html**: open in any browser. An interactive, LEGO-style build guide for a raised PVC dog cot made only from big-box plumbing parts. Use the arrow keys or swipe to step through.
- **plans/001-shelter-cot/README.md**: the same plan as plain text: parts, cut list, fabric template, open questions.
- **docs/**: business model notes, market research, and the app concept.
- **ROADMAP.md**: what's next.

## Picking this up in Claude Code

```powershell
cd C:\Projects\whisker-and-wrench
claude
```

Claude Code reads `CLAUDE.md` automatically for context.
