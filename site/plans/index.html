Drafts are drafts

"Draft" means the plan's dimensions are calculated, not yet measured on a real build. Dry-fit everything before you glue. If you build one, we'd love to hear how it went: open an issue on GitHub.

Build plans are free to use under CC BY-NC 4.0: build them, share them, adapt them for your shelter, just don't sell them. Site code is MIT licensed.
