# Plan 003: Modular Cat Tower

**Status: fit sheet only. Not a build guide.**

A modular cat tower is a set of PVC posts and wipeable shelves that comes apart for cleaning. Rooms are not one size, and no test tower has been built. This folder has no pipe lengths, no shelf sizes, no shopping list, no cut list, and no weight rating.

`measure.html` is the sheet a volunteer prints and fills in one real room. It asks for the floor spot, the overhead clearance, the path the pieces must travel, how that room is cleaned, and which cats will use the tower. The numbers stay on that paper.

Do not turn this into a guide until someone has filled the sheet in a real room and a test tower has been built and checked against those notes.
